# 🐸 FrogDrop

> A premium, minimalist macOS Menu Bar assistant that supercharges your drag-and-drop file organization and clipboard workflow.

## ✨ Features

* **📦 Interactive Dropzone**: Drag files to the Menu Bar item to "shelve" them. Tap on folders in your custom grid to move files instantly, or click built-in actions to run workflows (AirDrop, Email, Imgur upload, path copying).
* **📋 Clipboard History**: Automatically tracks copied texts, image snippets, and links. Pin your favorite items to keep them permanent.
* **🔗 Clipboard Link Shortener**: Spot a URL in your history? Hover over it and click the link-plus button to instantly shorten it using the built-in TinyURL integration.
* **🎨 Premium macOS Aesthetics**: Modern dark mode layouts, matched geometry pill highlights, bouncy spring hover animations, and an organic blooming-flower daily progress dashboard.
* **⚡ Standalone Agent Mode**: Runs entirely in the macOS Menu Bar (`LSUIElement = true`) without cluttering your system dock.

## 🚀 Installation & Setup

1. Go to the [Releases](https://github.com/sarthak-SyntaxSamurai/FrogDrop/releases) tab.
2. Download the latest `FrogDrop.zip` archive.
3. Double-click the zip to extract `FrogDrop.app`.
4. Drag `FrogDrop.app` into your **Applications** folder.
5. Double-click to launch! Give the app accessibility permissions if prompted to allow interactive drop targets.
